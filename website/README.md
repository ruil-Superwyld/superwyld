# Super WYLD Landing Page

Static landing page for `superwyld.com`.

## Files

- `index.html`: landing page markup
- `styles.css`: responsive visual system and layout
- `script.js`: interactive schedule calendar and form confirmation
- `assets/images/superwyld-logo-vertical.png`: vertical logo used in the header
- `assets/images/superwyld-logo-horizontal.png`: horizontal logo used in the footer
- `assets/images/miumiu-character.png`: MiuMiu character artwork used in the IP section
- `assets/images/miumiu-nav-hover.png`: small MiuMiu artwork used for navigation hover states
- `assets/images/superwyld-hero.png`: hero artwork
- `assets/fonts/`: place the supplied brand fonts here:
  - `AlimamaFangYuanTiVF-Thin.ttf`
  - `TENSANS-BOLD-2.otf`
